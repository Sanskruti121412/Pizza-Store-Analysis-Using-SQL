# Pizza-Store-Analysis-Using-SQL
- Pizza Sales Analysis – Data Analytics Project.
This project performs an end-to-end analysis of a pizza sales dataset.
Using Python (Pandas, Matplotlib, Seaborn), the project uncovers business insights that help understand revenue trends, ordering patterns, and customer behavior.

- Project Objectives:-
  Analyze revenue trends
  Identify top-selling pizza types
  Study customer ordering behavior
  Find distribution patterns across categories, time, and size
  Visualize insights using clear, informative charts

- Key Insights & Queries Answered:-
 1️⃣ Daily & Cumulative Revenue
  A line chart tracks daily revenue to show sales fluctuations.
  A cumulative curve demonstrates total revenue growth over time.
  Helps identify peak sale days and long-term performance patterns.

 2️⃣ Top 5 Most Ordered Pizza Types
  Aggregates order data to find the highest-selling pizzas by quantity.
  Useful for:
  inventory management
  promotional planning
  demand forecasting    

 3️⃣ Most Common Pizza Size Ordered
  Determines which pizza size (S, M, L, XL) dominates the orders.
  Helps optimize production and stocking of raw materials.

 4️⃣ Category-wise Distribution of Pizzas
  Counts number of pizza types in each category such as
  Classic, Supreme, Veggie, Chicken, Gourmet, etc.
  Useful for understanding menu composition & customer preference.

 5️⃣ Distribution of Orders by Hour of the Day
 Identifies peak business hours based on order timestamps.
 Helps restaurants optimize:
 staffing
 preparation time
 marketing campaigns

 - Visuals:-
   Daily revenue line plot
   Cumulative revenue graph
   Top-selling pizza bar chart
   Category distribution pie/bar chart
   Hourly order distribution
   
🚀 Conclusion:-
This project provides a full analytical breakdown of pizza sales data.
It helps understand customer preferences, peak revenue times, and menu performance—insights valuable for any food business aiming to optimize operations and boost profitability.
